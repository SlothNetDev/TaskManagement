Task Management API
This is a RESTful API for a task management application, built as a foundational project to demonstrate core API development principles.

Features
This API provides the following functionalities:

1. User Management
User Registration & Authentication: Secure user registration and login using JWT (JSON Web Tokens).

Profile Management: Ability to manage user profiles.

2. Task Operations
CRUD Operations: Full functionality to Create, Read, Update, and Delete tasks.

Task Details: Each task can have a category, priority, and a due date.

Status Tracking: Tasks can be tracked with statuses like Todo, In Progress, and Completed.

3. Advanced Features
Task Assignment: Assign tasks to specific users.

Filtering & Search: Easily find tasks by filtering or searching.

Pagination: Efficiently handle large lists of tasks.

Task Dashboard: View statistics and summaries of tasks.
